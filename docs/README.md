# Presentation materials

The original decks, HTML presentation, and Python generators were moved here during prototype cleanup. They have not been revised to reflect the authentication/history work or validated for scientific accuracy. Existing performance and accuracy claims may be illustrative.

The PowerPoint files remain available locally but generated `.pptx` and `.pdf` files are ignored by Git. Install `python-pptx` separately if you need to regenerate a deck, then run `python docs/generate_presentation.py` or `python docs/build_full_ppt.py` from the project root. Outputs are written beside the generators.
