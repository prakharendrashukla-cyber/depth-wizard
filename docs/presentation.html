The ISRO Challenge & Problem Statement

Why conventional multi-view stereoscopic elevation mapping falls short

⚠️ Limitations of Traditional 3D Mapping

  • Stereo Photogrammetry Needs Multi-Pass Pairs: Requires multiple orbital passes or dual-camera rigs with baseline angle constraints.
  • Missing Data in Lunar Poles: Chandrayaan-2/3 lunar south pole images have permanent shadows where stereo fails.
  • High Hardware & Weight Costs: Active LiDAR cannot be deployed on micro-satellites or tactical nano-drones.
  • Extreme Computational Complexity: Structure-from-Motion (SfM) takes hours of heavy multi-view point matching.

🚀 Depth Wizard Monocular AI Solution

  • Monocular Zero-Shot Elevation: Reconstructs high-precision 3D elevation from a SINGLE 2D optical image.
  • Vision Transformer Foundation Core: Pre-trained on multi-domain terrains for universal zero-shot generalization.
  • Sub-Meter GCP Metric Calibration: Least-squares regression converts relative depth into physical meters.
  • Real-Time WebGL & Geospatial Analytics: 3D point cloud, contour marching squares, volume, and PDF dossiers.

Ground Control Point (GCP) Metric Calibration

Mathematical affine least-squares regression anchoring relative depth to real meters

📐 Mathematical Formulation

  • Scale Ambiguity Resolution: Neural models produce normalized disparity d ∈ [0, 1].
  • Affine Regression Model: Height_m = Scale · d_norm + Offset
  • Normal Equations Matrix Fit: β = (X^T X)^(-1) X^T Y
  • Interactive UI: Place 2 to 10 survey markers on image canvas.
  • Confidence: R² > 0.95 (High), R² > 0.80 (Medium), R² < 0.80 (Low).

🎯 Real-Time Calibration Highlights

  • Canvas reticles with inline height survey inputs
  • Pre-calibrated satellite presets for Cartosat-3 & Chandrayaan-2
  • Per-point residual table showing predicted vs actual heights
  • Instant live metric scaling across 3D canvas and contour tools

Satellite & ISRO Orbital Telemetry Suite

🛰️ GeoTIFF & Orbital Metadata

  • Stage 01: Ingestion (~15ms): GeoTIFF tags, band splitting, canvas scaling.

  • Stage 03: 3D Point Cloud (~25ms): 55K vertex back-projection.
